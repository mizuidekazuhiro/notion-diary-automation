# Anki原本の取得停止と復旧

同期完了直後にAnkiがコレクション切替処理中の場合、`deckNames` / `cardReviews` の読取だけを最長20秒再試行する。同期処理自体は再実行しない。SQLiteの読取専用バックアップにも単調時計による20秒の総期限を設け、ロック中の無期限待ちを防ぐ。

どちらの読取にも失敗した場合、0分の集計を作成・送信しない。取得成功した原本が0レビューだった場合だけ、対象日のAnki正本0分を送信する。学習日の04:00 JST境界、既存の解答時間・Anki時間の扱いは変更しない。

回復確認は既存DPAPI設定を保持し、まず `--no-sync --dry-run` で原本の対象日・件数を確認する。通常更新では稼働コピーの未コミット変更を確認し、変更前ファイルを私有領域に退避してから検証済みスクリプトだけを反映する。初回登録用インストーラで資格情報を再作成しない。

回帰検証：既存WAL読取、排他ロック時の期限終了、一時的な同期後busyからの読取回復。原本の書換えや日記・メール送信はテストに含めない。
